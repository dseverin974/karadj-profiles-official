# KaraDJ — profils MIDI officiels

Catalogue officiel des profils de contrôleurs MIDI pour [KaraDJ](https://github.com/dseverin974). `catalog.json` est signé en Ed25519 (`catalog.json.sig`, signature détachée) ; la clé publique est `catalog-public-key.pem`. Chaque profil est vérifié par son SHA-256. Un profil est une donnée, jamais du code.

URL : https://dseverin974.github.io/karadj-profiles-official/catalog.json
